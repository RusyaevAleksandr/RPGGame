# RPG Game
* Цель: победить всех монстров, попасть в топ списка победителей по очкам. 
* В игре можно выбрать один из 4 классов для героя, каждый имеет свои уникальные характеристики и способности:
*  Класс Воин - имеет большой запас жизней, сильный удар, но слабую ловкость;
*  Класс Маг - имеет небольшой запас жизней, средний удар, среднюю ловкость;
*  Класс Лучник - имеет средний запас жизней, небольшой удар, высокую ловкость. Супер способность Лучника: критический удар - 25% шанс нанести критический удар, удваивающий урон;
*  Класс Целитель - имеет небольшой запас жизней, небольшой удар, среднюю ловкость. Супер способность исцеление - Исцеляет некоторое кол-во очков жизней с 15% вероятностью после каждой атаки.
* Игра написана на языке программирования C# с использованием Console App.
* Перед вами появляются монстры по очереди, вы должны сразиться с каждым из них.
*  После каждого выигранного сражения начинается мини-игра, поймай звезду. В течении 10 сек. появляются иконки, каждая пойманная иконка дает +1 к характеристикам героя (сила и ловкость.
*  Итоговый счет. Формула подсчета: Уровень героя умножить на 100 + сумма пойманных звезд за всю игру.

## При написании игры использовалось:
1. C#.
2. Console App.
3. Работа с вложенными циклами и математическими операциями.
4. Работа с ООП.
